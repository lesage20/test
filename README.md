## Stack

| Layer | Tech |
|---|---|
| Backend | Laravel 13 (PHP 8.3) |
| Bridge | Inertia.js v2 (SPA, SSR désactivé) |
| Frontend | Vue 3 + TypeScript + Vite |
| CSS | Tailwind CSS 3 |
| Icons | Lucide Vue Next |
| Admin | Filament v3 (panel `/admin`) |
| DB | MySQL 8.0 (Docker) |
| Tests | Pest 3 |
| Runtime | Docker Compose |

## Quick start (prod)

```bash
# 1. Build & start
sudo docker compose up -d --build

# 2. Run Filament admin installer (idempotent)
sudo docker compose exec app php artisan filament:install --panels --no-interaction

# 3. Create admin user
sudo docker compose exec app php artisan make:filament-user

# 4. Expose via Caddy externe (one-shot)
~/.hermes/scripts/caddy-add.sh test 3002
```

App : https://test.sagecoders.com · Admin : https://test.sagecoders.com/admin

## Local dev (sans Docker pour PHP)

```bash
# 1. Start only MySQL in Docker
sudo docker compose up -d mysql

# 2. Install deps locally
composer install
npm install
npm run dev

# 3. Migrate + serve
php artisan migrate
php artisan serve --port=3002
```

Then in another terminal:
```bash
~/.hermes/scripts/caddy-add.sh test 3002
```

## Endpoints

- `GET /` — Welcome page (Inertia)
- `GET /dashboard` — auth required
- `GET /admin/login` — Filament admin
- `GET /api/health` — health check (JSON)
- `GET /up` — Laravel built-in health probe
